État technique

—

Le moteur utilise des bougies historiques de 5 minutes. Les gains ne sont pas garantis. Les ordres sont sans frais dans le portefeuille principal; un second calcul estime les frais, le spread et le slippage, sans exécution réelle. Marchés fermés et cours anciens ne déclenchent pas d'ordres. Les données Yahoo peuvent être différées.

Sur l'offre Render gratuite, le service peut se mettre en veille et la base locale peut être effacée. Ce prototype n'est pas une simulation garantie 24 h/24 avec historique permanent.
